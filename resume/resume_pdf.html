프로젝트
🌐 Horizon SNS
개인 프로젝트  ·  horizonsns.com GitHub
실시간 채팅과 소셜 로그인이 가능한 풀스택 SNS 플랫폼 개인 개발 프로젝트입니다. Spring Boot 3 기반으로 JWT 인증, Google/Naver OAuth2 소셜 로그인, WebSocket 실시간 1:1 채팅, SSE 알림, AWS S3 및 OCI Object Storage를 이용한 미디어 업로드 등 SNS 핵심 기능을 구현하였습니다.
  • 피드 조회 성능 개선 (단계적 최적화) — 1:N 다중 leftJoin 카르테시안 곱 문제(post × likes × comments 행 폭증 + 임시 테이블 생성) 발견, 쿼리 최적화 및 복합 인덱스 적용으로 응답시간 750ms → 15ms / K6 부하테스트(100VU) CPU 100% 도달 확인 → Spring Cache + Redis 캐싱 도입 및 불필요한 member 재조회 제거로 추가 개선 / 캐싱 적용 후 400VU에서도 안정적인 응답 확인
  • 커서 기반 페이지네이션 도입 — 10만 건 기준 offset 방식은 페이지 깊어질수록 최대 300ms까지 증가하는 반면, cursor 방식은 150ms로 일정함을 직접 검증 후 무한 스크롤에 cursor 방식 적용
  • CDN 도입 — AWS S3 + CloudFront 연동으로 이미지 응답속도 개선, 캐싱 적용 후 재요청 응답시간 62% 감소
  • 인증 / 보안 — JWT Access + Refresh Token 및 OAuth2 소셜 로그인(Google, Naver) 구현, Let's Encrypt HTTPS 적용
  • 실시간 통신 및 알림 — WebSocket STOMP 프로토콜 기반 1:1 채팅, SSE(Server-Sent Events) 기반 실시간 알림(좋아요·댓글·답글)
  • 스토리지 정합성 — 파일 삭제 API 실패 시 S3에 고아 파일이 남는 문제 발견, Outbox Pattern 도입으로 DB 트랜잭션과 외부 스토리지 작업 간 정합성 보장
  • 인프라 자동화 — GitHub Actions CI/CD 파이프라인 구축, nginx 리버스 프록시로 OCI 서버 자동 배포
